# Plan Node 2465: Mechanical Shell Closure Orchestration

## Goal
Create `bin/dyad-shell-hooks.sh` to trap CLI exits and trigger telemetry sweeps.

## Tasks
1. **Create Shell Hook**: Implement `bin/dyad-shell-hooks.sh` containing `agy_dyad()` and `claude_dyad()`. The hook will proxy arguments to the underlying binary, and then upon return of control, execute `if [ -f "./bin/status" ]; then ./bin/status; fi`.
2. **Make Executable**: Ensure `bin/dyad-shell-hooks.sh` has executable permissions (`chmod +x`).
3. **Unit Testing**: Create `tests/test_shell_hooks.py` using `unittest` and `subprocess` to assert that sourcing the script and running a mock `agy` command successfully triggers a mock `./bin/status` script.
4. **Reflect**: Close the node successfully, which paves the way for the Act node (#2466).
