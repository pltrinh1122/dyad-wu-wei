# Plan - Remediate DAG Execution and NBA Fallback Invariants

## 1. Technical Design

### A. The Abort / Orphan State Fix
In `kernel/node_lifecycle.py`, the `abort()` method currently fails to reset the status properly and permanently strands nodes by not restoring the `backlog` label.
- Change `self.set_status("open")` to `self.set_status("todo")`.
- Introduce `self.set_classification("backlog")` directly after the status reset to ensure the node re-enters the active backlog.

### B. The Terminal Reflect Invariant (DAG Rewiring Elimination)
Instead of building complex regex string replacers in `daemon_backlog.py` to rewrite `[Depends: XXX]` pointers when injecting new `Act` nodes, we will implement a structural invariant in the DAG evaluator.
- In `drivers/gh_graph_skill.py` (`get_ready_nodes`):
  - Check if any incomplete node has "Reflect" in its title.
  - If it does, strictly enforce that it CANNOT be returned as "ready" unless `len(incomplete_ids) == 1` (meaning it is the sole remaining node in the Meta-Index).
  - This mathematically guarantees that `Reflect` executes last, regardless of corrupted or stale `Depends` text in the issue body.

### C. The Universal NBA Topological Evaluation
In `kernel/daemon_nba.py`, the fallback logic for `unmatched_items` currently ignores DAG structure.
- We will consolidate ALL open Paths (both from `strategic_intent.yml` and generic BUG paths) into a unified DAG evaluation pass.
- We will iterate over all open `Path` issues in the system, extract their `Meta-Index` using `gh_graph_skill`, and append their ready nodes to the `recommendations` pool.
- The `unmatched_items` fallback will be restricted strictly to non-Path issues (e.g., standalone issues that have no Meta-Index).
- We will explicitly filter out any issue starting with "Path:" from `unmatched_items` so that the NBA never attempts to auto-lock a container node.
