# Plan: Autonomous Domain Delegation and Healer Protocol (Path 2152)

## Context
As aligned in `discovery_2152.md`, we need to implement the Healer Protocol by allowing specialized subagents (e.g., `agent-healer`) to own Administrative nodes for `[BUG]` paths and ensuring execution nodes (`Act`) within those paths bypass HTIL review when local CI passes.

## Implementation Steps

### 1. Update `kernel/daemon_strategic.py`
In `auto_resolve_persona`, we currently have a hardcoded check:
```python
if "harmonize" in node_title.lower() or "plan" in node_title.lower() or "reflect" in node_title.lower():
    return "frontier"
```
We need to modify this logic so that if the parent path title starts with `[BUG] Intake`, it resolves to `'agent-healer'`. We must inspect the parent path title via the `node_id` or passed metadata. If `node_title` itself contains the path context, we can just do:
```python
if "harmonize" in node_title.lower() or "plan" in node_title.lower() or "reflect" in node_title.lower():
    if "[bug] intake" in node_title.lower():
        return "agent-healer"
    return "frontier"
```

### 2. Update `kernel/node_lifecycle.py`
In the `Act` reflection logic (`reflect`), we currently check:
```python
if "harmonize" in title.lower() or "plan" in title.lower():
    # ... bypass htil ...
```
We need to add a condition for `Act` nodes inside `[BUG]` paths:
```python
is_bug_path_act = "act" in title.lower() and "[bug] intake" in title.lower()
if "harmonize" in title.lower() or "plan" in title.lower() or is_bug_path_act:
    try:
        github_client.add_label(issue_id, "htil-bypass")
```

### 3. Update `kb/WHAT-0065-persona-domain-ownership.md`
Add `agent-healer` to the list of defined personas:
```yaml
agent-healer:
  domain: Metasystem / Healing
  description: Autonomous crash resolution and bug fixing.
```
This ensures the subagent dispatcher can recognize `agent-healer`.
