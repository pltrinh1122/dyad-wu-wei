# Plan for Node 2112: Kernel Daemon Local Invariant Isolation (Filesystem State)

## 1. Goal
Implement local invariant isolation for the kernel_daemon, as outlined in the `WHAT-2110.md` intake. The `WipN1Guard` must be updated to only evaluate git worktrees that correspond to the current persona's active node.

## 2. Approach
- **`kernel/daemon_node.py`**:
  - In `run_sync_daemon`, inject logic to filter the `open_worktrees` list returned by `get_local_worktrees`.
  - Read `SPAO_PERSONA_ID` from the environment (defaulting to `frontier`).
  - Read `artifacts/frontier_state.yml` to map personas to their currently active nodes using `agent_frontier.read_active_nodes`.
  - Ignore any worktree whose issue number maps to a node currently active for *another* persona.
  - If a worktree does not belong to another persona's active node, it will be evaluated normally (allowing the kernel_daemon to detect orphans or the persona's own worktrees).

## 3. Validation
- Ensure `bin/run-tests` passes completely offline.
- Ensure the reflection mechanism completes correctly for this node.
