# Plan: System Crash in reflect (Node 2119)

## Goal
Prevent intentional `REFLECTION BLOCKED` enforcement (mandated by SG-0005) from triggering a global System Crash Bug Report. The bug reporting mechanism should only catch unexpected execution crashes, not intentional audit failures.

## Implementation Steps

1. **Define `ReflectionBlockedError`**
   - File: `kernel/node_lifecycle.py`
   - Action: Add `class ReflectionBlockedError(Exception): pass` below the existing `StateDissonanceError`.

2. **Raise `ReflectionBlockedError`**
   - File: `kernel/daemon_knowledge_accrual.py`
   - Action: Import `ReflectionBlockedError` from `kernel.node_lifecycle`.
   - Action: In `enforce_reflection_hook()` and `enforce_operator_positive_feedback_hook()`, change `raise Exception(...)` to `raise ReflectionBlockedError(...)` when a required retrospective or knowledge base file is missing.

3. **Gracefully Catch the Error**
   - File: `kernel/daemon_node.py`
   - Action: Import `ReflectionBlockedError` from `kernel.node_lifecycle`.
   - Action: In `main()`, locate the `except (ValidationError, StateDissonanceError) as ve:` block (around line 833).
   - Action: Expand the exception tuple to `except (ValidationError, StateDissonanceError, ReflectionBlockedError) as ve:`.
   - Impact: This ensures the blocked reflection will print `[🚫 BLOCKED] Execution Blocked: REFLECTION BLOCKED...` and safely execute `sys.exit(1)`, bypassing the `except Exception as e:` block that autonomously files a crash report bug.

4. **Update Tests**
   - Files: `tests/test_knowledge_accrual.py`, `tests/test_operator_correction.py`
   - Action: Optionally update test assertions from `pytest.raises((Exception, SystemExit))` to `pytest.raises((ReflectionBlockedError, SystemExit))`. The `match="REFLECTION BLOCKED"` parameter will ensure the tests continue to pass.
