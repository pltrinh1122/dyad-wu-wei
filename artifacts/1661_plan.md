# 1661 Plan: Intake System Crash in checkout

## Implementation Plan
This node serves as the formal planning phase for resolving the `checkout` system crash (Issue #1659).

### Context
During Node 1660 (Discovery), we determined that the root cause of the crash was a missing `SPAO_PERSONA_ID` environment variable fallback for commands executed directly in the root repository. The `daemon_strategic.py` gateway would raise an exception (`Persona Gate Blocked`) because the `"frontier"` fallback was conditionally restricted to nested workspaces.

### Required Changes
No codebase modifications are required. The `checkout` command crash was already implicitly fixed by **PR #1722**, which implemented `# 4. Root system daemon fallback` in `kernel/daemon_strategic.py`. 

### Validation Strategy
- We have manually verified that running `./bin/node checkout` from a stripped environment successfully auto-resolves the persona to `'frontier'` and proceeds without exception.
- No new automated tests are required as this is covered by the fallback implementation's existing verification.

### Contract
