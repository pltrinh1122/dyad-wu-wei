# Plan - Node 2174: System Crash in checkout

## Implementation Plan
1. **Define `CheckoutBlockedError`:** In `kernel/node_lifecycle.py`, add `CheckoutBlockedError` alongside `ReflectionBlockedError` and `StateDissonanceError`.
2. **Handle `CalledProcessError`:** In `kernel/node_lifecycle.py`'s `checkout` method, wrap `git_client.worktree_add` in a `try...except subprocess.CalledProcessError` block. If caught, raise a `CheckoutBlockedError` indicating a stale local git state.
3. **Graceful Daemon Exit:** In `kernel/daemon_node.py`'s main exception handler, import and add `CheckoutBlockedError` to the tuple of gracefully caught execution exceptions (`ValidationError`, `ReflectionBlockedError`, etc.), allowing it to be surfaced as a `[🚫 BLOCKED]` transaction without raising a native Python traceback.
