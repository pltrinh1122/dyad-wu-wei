# 2011 Plan: Enforce Prompt Queue Clearance Guard

## Rationale
To prevent the agent from dropping into autonomous DAG execution while leaving conversational prompts unaddressed, we must enforce a physical boundary. If `artifacts/prompt_backlog.yml` contains pending prompts, commands that attempt to execute autonomous SPAOR loop steps (like `sync-clean` or `plan-start`) must halt immediately with an HTIL exception, compelling the operator (or agent) to consume the queue via `bin/prompt process`.

## Technical Strategy
We will implement a Lexical Guard at the start of the two primary engine triggers:
1. `kernel/node_lifecycle.py::TerminalNode.plan_start()`
2. `kernel/daemon_node.py::sync_and_clean_node()`

Both functions will invoke a check against the prompt backlog size.

### Implementation Details

**1. `kernel/node_lifecycle.py`**
In `TerminalNode.plan_start()`, immediately following the `check_nba_handoff()` block, we will add:
```python
        from kernel.daemon_status import get_prompt_backlog_size
        from drivers.path_resolver import get_workspace_dir
        if get_prompt_backlog_size(get_workspace_dir()) > 0:
            print("🚨 **[HTIL GATE ENGAGED: CONVERSATIONAL_ALIGNMENT]** 🚨")
            print("Pending operator prompts detected. You must clear the prompt queue using `bin/prompt process` before acquiring a new Node lock.")
            sys.exit(1)
```

**2. `kernel/daemon_node.py`**
In `sync_and_clean_node()`, at the very beginning of the function:
```python
    from kernel.daemon_status import get_prompt_backlog_size
    from drivers.path_resolver import get_workspace_dir
    if get_prompt_backlog_size(get_workspace_dir()) > 0:
        print("🚨 **[HTIL GATE ENGAGED: CONVERSATIONAL_ALIGNMENT]** 🚨")
        print("Pending operator prompts detected. You must clear the prompt queue using `bin/prompt process` before synchronizing the DAG.")
        import sys
        sys.exit(1)
```
