# Plan for Node 2047: Falsify Triage Holding and Implement Prompt Routing Survivor

## Objective
To eliminate the administrative drag of the `Triage Holding` Path by falsifying its utility for internal system daemons. Instead, we will implement the "survivor" routing: system-generated alerts will be injected directly into the Prompt Queue via `bin/prompt`. 

## Rationale
- **Agentic Healing**: By routing structural alerts (like Backlog Hygiene Warnings) into the Prompt Queue, the active agent is forced to process them before DAG autonomous execution can continue (enforced by the `Enforce prompt queue clearance` guard). This triggers an immediate self-healing loop.
- **Zero Graveyard**: No more "Triage Holding" paths that require full `Plan/Harmonize/Reflect` ceremonies just to exist as a passive bucket.
