# 2005 Plan: Automated Hygiene Sweep - Orphaned Terminal Nodes

## Root Cause Analysis
During the Harmonize phase, we investigated why `daemon_backlog.py` failed to append the newly generated child nodes (e.g., 2000, 2001, 2002) to the `## Meta-Index` section of the parent Path (1999).

The investigation revealed that `kernel/daemon_backlog.py` (around line 246) handles updating the parent body by appending the checkbox string directly to the absolute end of the issue body:
```python
            if "## Meta-Index" in path_body:
                path_body += f"\n{checkbox_line}"
            else:
                path_body += f"\n\n## Meta-Index\n{checkbox_line}"
```

However, the template used for Path trackers (`kb/templates/path_tracker.md`) contains additional sections below `## Meta-Index`, specifically `## Agent Retrospective`. By appending the checkbox string to the absolute end of the file, the checklist items are placed beneath `## Agent Retrospective`.

The hygiene daemon (`drivers/audit_daemon.py` -> `kernel/daemon_backlog.py::sweep_orphans()`) extracts the `Meta-Index` using a regular expression that explicitly stops capturing at the next `##` header or end-of-string:
`re.search(r"## Meta-Index\s*\n(.*?)(?=\n##|\Z)", body, re.IGNORECASE | re.DOTALL)`

Since the checkboxes were appended at the end of the issue (below the `## Agent Retrospective` header), they were not captured by the `sweep_orphans()` regex. Consequently, the nodes were incorrectly flagged as "orphaned terminal nodes."

## Technical Design
To rectify this issue, we must update the logic in `kernel/daemon_backlog.py` to insert the checkbox line directly under the `## Meta-Index` header, rather than at the end of the `path_body`.

### Modifications
1. **File**: `kernel/daemon_backlog.py`
2. **Function**: `BacklogDaemon.add()`
3. **Change**: Replace the absolute append logic with a regex substitution that injects the checkbox directly beneath the `## Meta-Index` header line.

```python
            if "## Meta-Index" in path_body:
                import re
                # Insert the checkbox line directly under the Meta-Index header
                path_body = re.sub(r"(## Meta-Index[ \t]*\r?\n)", r"\1" + checkbox_line + "\n", path_body, count=1)
            else:
                path_body += f"\n\n## Meta-Index\n{checkbox_line}"
```

This change ensures that dynamically generated child nodes correctly populate within the scope of the `Meta-Index` section, preventing false-positive orphans in future automated sweeps.
