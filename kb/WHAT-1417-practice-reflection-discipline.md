# WHAT-1417: Practice Reflection Discipline

## 1. Intent
To formally codify the **Practice Reflection** discipline for the Frontier Dyad. This is a non-clinical learning loop executed at natural rest points (e.g., node completions, path closures) to capture lived operational practices in the durable record. This discipline was sourced from the Healer Dyad's practice.

## 2. Structural Primitives
A Practice Reflection uses a structured **Continue / Start / Stop (CSS)** framework, paired between substrates (Agent details + Operator narrative).

- **CONTINUE**: Systemic behaviors, disciplines, or patterns that functioned correctly and should be preserved.
- **START**: Specific improvements or newly identified falsifiable rules to begin doing.
- **STOP**: Specific anti-patterns or practices that caused friction and must be halted.

## 3. Integration Sequence (The Four-Step Form)
The reflection process demands engagement from both substrates to close the loop:
1. **Agent-led Drafting**: The Agent drafts the narrative summary and details bullets for each CSS section.
2. **Operator POV**: The Operator provides their narrative for each section (or indicates no POV).
3. **Agent Falsification**: The Agent tests the Operator's POV claims against the chat-history evidence.
4. **Integration & Ratification**: The Agent integrates surviving POVs into the reflection artifact and the Operator ratifies the final version.

## 4. Execution
The Agent maintains the template at `kb/templates/practice_reflection.md` and generates reflections into `artifacts/audit/retro-<context>.md`.
