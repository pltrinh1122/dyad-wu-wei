# Intent
To permanently elevate the Main Agent to act solely as the strategic kernel_daemon, we must separate high-level design thinking from low-level execution. This requires decoupling the Main Agent's execution loop from local execution friction.

# Context
Currently, the SENSE phase's WIP=1 check evaluates all git worktrees present in `.worktrees/`. If a sub-agent is executing a task in a parallel worktree, the Main Agent sees this worktree and halts its own execution loop, falsely believing it is already engaged in a node. This prevents concurrent execution and halts the Main Agent from orchestrating further nodes. 

# Value
By ensuring that the SENSE phase only evaluates git worktrees owned by the current persona (or matching the current persona's active node), the Main Agent can maintain its own WIP=1 invariant independently of any dispatched sub-agents. This unlocks concurrent dispatch and preserves the autonomy of the Strategic Kernel Daemon.
