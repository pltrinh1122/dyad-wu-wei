# WHAT: Decoupled Ledger Architecture Implementation Plan

## Goal
Implement Option D garbage collection to autonomously close exhausted Path containers.

## Design
1. In `drivers/gh_graph_skill.py` (or `github_client.py`), add a function `check_off_node_in_parent(child_id: str)`:
   - Use `gh issue list --search "{child_id} in:body" --state open` to find the parent Path.
   - Fetch the parent's body, and use regex to replace `- [ ] #{child_id}: ...` with `- [x] #{child_id}: ...`.
   - Update the parent's body via the GitHub API.
2. In `kernel/node_lifecycle.py` inside the `reflect` function, invoke `check_off_node_in_parent(self.issue_id)`.
3. This ensures that every time a node is successfully reflected, it automatically checks itself off in the parent's Meta-Index.
