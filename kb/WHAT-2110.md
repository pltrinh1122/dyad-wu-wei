# Scope
Modify the SENSE phase logic (specifically local invariant checks) to only evaluate git worktrees that correspond to the current persona's active node.

# Requirements
1. Update local invariant checks to cross-reference `.worktrees/` entries with the current `SPAO_PERSONA_ID`'s active node in `artifacts/frontier_state.yml`.
2. Ensure `WIP=1` checks pass for the Main Agent even if other sub-agents have active worktrees.
3. Validate that node synchronization logic ignores or correctly attributes worktrees to their owning personas.

# Technical Strategy
- Refactor the logic in `drivers/local_invariant_driver.py` (or the equivalent module handling local sync and workspace evaluation).
- Introduce a mapping or check that verifies if a worktree's node ID matches the `current_active_node` of the executing persona.
- Update `bin/node sync` or `kernel/daemon_node.py` logic where worktree sizes/counts are evaluated to enforce the WIP=1 invariant.
