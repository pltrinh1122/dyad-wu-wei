# WHAT: Implement resilient GitHub CLI wrapper

## Goal
The GitHub CLI tool recently deprecated the GraphQL classic projects field, breaking the raw GitHub CLI issue viewer command. Since this viewing command is deeply ingrained in the system's manifold and relied upon heavily for node status checking and backlog parsing, we must provide a resilient wrapper that avoids deprecation errors without forcing the Agent to adopt new tools.

## Architecture
1. **Shell Entrypoint (`bin/gh`)**: Maintain the executable that delegates to Python execution for advanced handling.
2. **Python Wrapper (`drivers/gh_wrapper.py`)**: Intercepts command-line arguments.
3. **Interception**: If the arguments exactly match the issue viewing command (without format flags like `--json` or `--web`), rewrite the command to explicitly request `--json number,title,state,body,labels`.
4. **Custom Rendering**: Parse the JSON output and render it in a clean, human-readable format that mimics the standard output, ensuring compatibility with all downstream parsers.

## Success Criteria
- The custom executable successfully parses and prints the details without any GraphQL deprecation warnings.
- The command transparently passes through other arguments directly to the system binary.
