# WHAT-2356: Refactor frontier_file to Named Argument

## Context
Agents routinely crashed the `bin/node reflect` execution step by mistakenly providing a 7th positional argument. Because `frontier_file` was defined as `nargs="?"` (an optional positional argument), `argparse` bound the provided trailing arguments to `frontier_file`.

## Change
- `frontier_file` is now an optional named flag: `--frontier-file` in both `reflect` and `cancel` subcommands within `kernel/daemon_node.py`.
- This ensures trailing positional arguments result in an immediate clear `argparse` validation error rather than attempting to load frontier state from the wrong file.
