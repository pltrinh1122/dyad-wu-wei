# WHAT-0056: Daemon Backlog Meta-Index Insertion

## Purpose
Specifies the exact insertion behavior required for appending dynamically generated nodes (such as those generated by the hygiene sweep or triage holding) to their parent Path's `Meta-Index` list.

## Problem Statement
Previously, `kernel/daemon_backlog.py` updated a parent path's body by simply appending the new checkbox line to the absolute end of the file string (`path_body += f"\n{checkbox_line}"`). Because templates like `kb/templates/path_tracker.md` include structural sections *below* `## Meta-Index` (such as `## Agent Retrospective`), the appended checkboxes would land below the final headers. Subsequently, extraction regexes (like those in `drivers/audit_daemon.py`'s `sweep_orphans` logic) failed to capture them, classifying these successfully created nodes as "orphaned terminal nodes."

## Specification
1. When `daemon_backlog.py` updates the parent issue's body to append a `- [ ] #ID: ...` checklist item:
   - If the `## Meta-Index` header exists, the system MUST use a regex substitution to inject the new checklist item **directly beneath** the `## Meta-Index` header.
   - Example Regex Substitution: `re.sub(r"(## Meta-Index[ \t]*\r?\n)", r"\1" + checkbox_line + "\n", path_body, count=1)`

2. This guarantees all generated checklist items correctly reside within the parsed bounds of the `Meta-Index` section.
